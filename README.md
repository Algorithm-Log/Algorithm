# 🚀 Algorithm Study

알고리즘 문제 해결 능력 향상과 꾸준한 기록을 목표로 하는 SSAFY 16기 알고리즘 스터디입니다.

## 📌 Study Rule

### 1. 문제 풀이

- 매주 선정된 알고리즘 문제를 풀이합니다.
- 매주 수요일 12:00까지 풀이 완료 후 Push 합니다.
- 풀이 과정과 접근 방법을 Pull Request에 작성합니다.
- 매주 자신에게 선정된 문제 폴더를 꼭 만들어서 push 합니다.

# 🌱 Commit Convention

커밋 메시지는 아래 형식을 사용합니다.

## Commit Type

| Type | 설명 |
|---|---|
| Init | 문제 파일 추가 |
| Solve | 문제 풀이 완료 |
| Fix | 코드 수정 |
| Refactor | 코드 개선 |
| Docs | README 수정 |

Commit Type: [Week] 문제명 - 이름


예시:


Solve: [1week] SWEA_1234_괄호 - 강예린
